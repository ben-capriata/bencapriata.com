What I do

Three things, done properly.

Design the system

Tracker programmes, metadata dictionaries, indicator sets, and data entry forms that field staff can use without a manual. The unglamorous part is where implementations succeed or fail.

Connect the systems

OpenHIE-style interoperability layers so laboratory, facility, and surveillance data stop living in separate buildings. Built to run on real ministry infrastructure, including air-gapped networks.

Make it answer questions

Reporting, dashboards, and AI-assisted analysis that a programme manager can act on the same morning, not a quarter later.

Selected work

Systems in production.

Harmony & Heart Initiative

HH-CBS-01 National system

A DHIS2 HIV case-based surveillance system and data warehouse running across all five Regional Health Authorities, delivered with CDC, HRSA, and I-TECH. It is the backbone of national HIV programme reporting in Trinidad and Tobago.

Nominated for the IDB PRAISE 2025 innovation award.

Rapid Testing site management

RT-SITE Tracker programme

Site registration, coded site identifiers, facility tracking, and an SPI-RRT audit stage, so quality assurance visits produce structured data instead of a folder of scanned forms.

Interoperability layer

OHIE-01 Integration server

OpenHIM, JeMPI, HAPI FHIR, and a self-hosted OpenFn Lightning instance, standing up DHIS2-to-DHIS2 and SFTP-to-DHIS2 pipelines inside a restricted ministry network.

Custom DHIS2 applications

APP-SUITE Application set

Print-ready register and audit report apps, user management tooling for laboratory staff, and reporting templates built to match the documents clinics already recognise.
